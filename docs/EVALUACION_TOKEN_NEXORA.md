# Evaluación inicial de token: NEXORA Token (NXR)

## Nombre propuesto
- **NEXORA Token**
- Símbolo tentativo: **NXR**

## Criterios mínimos antes de lanzamiento
1. KYC completo y auditado
2. Programa AML operativo
3. Opinión legal por jurisdicción
4. Tesorería > 18 meses
5. Política de market-making transparente

## Recomendación actual
Con el estado MVP actual, **no se recomienda** lanzar token aún en mercado abierto.
Primero completar seguridad, cumplimiento y operación multi-región.
